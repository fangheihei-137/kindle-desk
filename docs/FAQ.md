# 常见问题

**所有老 Kindle 都能装吗？**

目前只实测 KT2（2014）/ 5.12.2.2 / 600×800。其他机型需要确认屏幕、触摸输入、`eips` 与启动环境，欢迎适配反馈。此仓库不提供“全型号一键越狱”。

**必须一直开电脑吗？**

不需要。程序与数据在 Kindle 本地，电脑只用于初次安装或更新。手机扫码管理需要同一局域网。

**不用联网可以做什么？**

本地日程、待办、番茄钟、时钟、农历照常工作；天气保留最后缓存，资讯只保留最近 48 小时。

**天气城市不正确？**

自动定位依赖网络出口 IP，不是 GPS。请在手机管理页填写城市名；找不到时可试拼音或英文名。

**点开后退出、或打不开？**

先查看设备 `kindle-standalone/data/bootstrap.log` 和 `app.log`。常见原因是 Python 路径不对、缺少 Pillow/字体、另一全屏应用还在运行，或设备型号不兼容。提交问题时不要附完整个人数据或连接二维码。

**手机扫码打不开？**

确认 Kindle 和手机在同一 Wi-Fi、看板仍在运行；访客 Wi-Fi 或路由器设备隔离会阻止访问。更换网络后重新扫码。不要将这个本地 HTTP 服务映射到公网。

**手机保存出现 Forbidden？**

看板重新启动后请关闭旧网页，重新扫码；旧网页的表单凭据会过期。当前版本保留同源检查及表单防伪校验，不需要关闭它们。

**全刷时为什么会闪一下？**

这是墨水屏清理残影的正常全屏刷新。当前设置为首次全刷、每 10 次实际画面变化全刷，相同画面不计数。番茄钟圆环约每 15 秒更新，不做每秒动画。

**这能同步 Google / 苹果 / Outlook 日历吗？**

目前是手动填写，支持 Kindle 本机、手机和电脑编辑；没有接入云日历。欢迎通过 Issue 讨论后续方向。

**为什么仓库没有我的日程文件？**

每台设备首次安装时生成空数据和独立随机凭据。真实 `data/`、无线连接文件、备份和运行日志都不公开。演示图使用虚构数据。

**待机省电是否已经验证？**

KT2 最近三段待机累计约 73 小时，电量 73%→62%，无持续刷屏或异常退出；详细区间和限制见 [更新记录](../CHANGELOG.md)。这是单台设备实测，不是全机型续航承诺。进入待机有系统过渡时间，显示壁纸不等于立刻深度休眠。

**唤醒后天气暂时更新失败？**

无线网络重新连接需要时间，期间显示缓存并按更新周期重试。可连接成功后手动刷新。
